## Key Decisions
- **Release workflow**: Changed to `push: tags: ['v*']` — release is created only when a matching tag is pushed, not on every main branch push.
- **Version bump**: 0.8.0 → 0.9.3 (skipped 0.9.0-0.9.2 since those tags were local only, never pushed).
- **Meeting Assistant GUI**: egui/eframe (native, no WebView2) — chosen over WebView2 for smaller binary, no WebView2 runtime dependency.
- **Meeting Assistant providers**: Local-only (whisper.cpp STT + Ollama translate/suggest/summarize) — no cloud providers in scope.
- **Meeting Assistant config**: Separate file (`{config_dir}/RTeamsMeetingAssistant/config.json`) — independent from main app.
- **Communication**: Shared file + named pipe (Phase 3) — mini app sends realtime transcript to main app via `\\.\pipe\rteams-meet-assistant`.
- **Workspace**: Mini app is a workspace member (`members = ["rteams-meeting-assistant"]`) in root `Cargo.toml`.
